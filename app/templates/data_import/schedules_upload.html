Which file should I use?

Best: the Synergy U-SCH100 schedule export (Excel). One file covers your whole caseload, the fields are exact, and it keeps working if the printed layout ever changes. Required columns: Course ID, Course Title, Term Code, Begin Period, Staff Name — plus Perm ID or Student Name so each row can be matched to a student.
