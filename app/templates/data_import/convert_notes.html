Notes → Activity Log & Service Records

This tool converts your existing Counseling Notes into Activity Log entries (use-of-time tracking) and Service Records (per-student service history).

How it works:
  • Each note creates an Activity (tracks your time by ASCA category)
  • Each note creates a Service Record (tracks services per student)
  • Note type is mapped to the correct ASCA service type automatically
  • Duplicates are detected and skipped — safe to run multiple times
  • Your original notes are not modified or deleted
