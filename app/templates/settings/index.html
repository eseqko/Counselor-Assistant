Checking Ollama status...
Setup instructions
  1. Install Ollama: visit ollama.com and download for your OS
  2. Open a terminal and pull a model:
    • ollama pull gemma4:e4b — recommended (good quality, runs on most hardware)
    • ollama pull gemma4:e2b — fastest, lowest RAM usage (~3 GB), great for older machines
  3. Start Ollama: ollama serve (runs in background)
  4. Come back here and click "Save" — AI features will activate automatically

Tip: Prompts are optimized for small local models (2B-4B parameters). Larger models produce better output but require more RAM and are slower.
