What's included?
  • Caseload: Students, tags, counselor notes (including follow-up completion status), service records, transcript records
  • Course Catalog: School setup (name, colors, mascot), departments, courses, graduation requirements
  • Existing students are matched by Student ID — duplicates are updated, not created twice
  • Courses are matched by course number — existing courses are skipped

Setup instructions
  1. Install Ollama: visit ollama.com and download for your OS
  2. Open a terminal and run: ollama pull llama3.2:3b
  3. Start Ollama: ollama serve (runs in background)
  4. Come back here and click "Save" — AI features will activate automatically
