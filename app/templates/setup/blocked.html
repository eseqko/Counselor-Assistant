Setup has to be finished on this computer

First-time setup is the one moment the app has no account to check yet, so it only accepts the setup wizard from the computer running Counselor Assistant. That stops anyone else on the network from claiming the account before you do.

Open http://127.0.0.1:5000/setup directly on that computer and you'll get the wizard.

Setting up deliberately from another device? Start the app with COUNSELOR_ALLOW_REMOTE_SETUP=1 to allow it. If you just used Reset App from this device, go back and click the link again — a reset carries its own permission to finish setup here.
